# Archive contents

../../archive/CVC MCP contains the later per-task scripts, XPL2 extracts, sanitized driver catalog, downloaded Samsung driver, generated FirstAIproject versions and backups.

../../archive/CUE Docs/cvc-driver-mcp contains the initial MCP prototype, parser, earlier generators, tests, library notes and generated project artifacts. Relative placement preserves the imports used by the later scripts. Some hardcoded paths and working-directory assumptions still refer to the original PC; review before execution.

The parser and CRC implementation are also copied into this skill's scripts directory for standalone use. Run `node scripts/inspect-project.mjs <project.cvcp> <analysis-output-directory>` from the skill folder to inspect a copy.

Original analysis/HouseNechanice extraction is intentionally not included; it contained private installation data. The installed CVC Data tree and EXE are not copied. Original chat text and screenshots are not included: this package is reusable knowledge and local work artifacts, not a verbatim conversation export.

Project versions are experiments with different known defects. v06 is the latest generated file, not a certified release. Read SESSION-KNOWLEDGE.md before selecting a version.

This Downloads package is not automatically installed as a skill. To install later, copy only cue-visual-composer into the user's .codex/skills directory. Keep the archive available separately if historical examples are needed.
